  • Dark palette: brand panel #171C2D, auth panel #0B0E17, charcoal #0F1221, lavender button #EDEBFF / hover #DCD6FF / pressed #C9BFFF, button text #0F1221, focus ring #B84DFF. Use restrained coral/orange/violet accents only.
